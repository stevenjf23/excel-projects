
# 📅 Agenda Anual en Excel

Proyecto desarrollado en Microsoft Excel para la organización de tareas, eventos y actividades durante todo el año.  

## ✨ Características

- 📆 Vista anual por meses
- 🗓️ Calendario semanal organizado por días
- ✍️ Espacios para agregar tareas y recordatorios
- 🎯 Diseño simple y fácil de utilizar

## 📂 Archivo del Proyecto

Puedes descargar el archivo `.xlsx` y utilizarlo o modificarlo según tus necesidades.

## 📌 Objetivo

Facilitar la planificación y el control de actividades personales, académicas o laborales en una sola hoja de cálculo.
