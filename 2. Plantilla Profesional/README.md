# 📊 Plantilla de Resultados Financieros y Métricas Operativas

Proyecto desarrollado en Microsoft Excel para el seguimiento, análisis y visualización del rendimiento financiero y operativo plurianual (Histórico de 3 años: 20X1 - 20X3).

## 📂 Archivo del Proyecto
Puedes descargar el archivo `.xlsx` y utilizarlo o modificarlo según tus necesidades.

## 📌 Objetivo

Proporcionar a emprendedores, analistas y gestores de proyectos una herramienta visual y directa para evaluar la salud financiera y comercial de su negocio, facilitando la toma de decisiones estratégicas basadas en el crecimiento de clientes y la evolución del servicio.
